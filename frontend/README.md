# Northstar Warehouse Management System

A web-based Warehouse Management System developed as a 2-person software engineering project.

## Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide
- Recharts

## Backend

- Node.js
- Express.js
- PostgreSQL
- Prisma

## Frontend Modules

- Dashboard
- Inventory / Stock Intake
- Chambers / Allocation
- Withdrawals
- FIFO Dispatch
- Alerts
- Rent
- Payments
- Staff Tasks
- Reports
- Audit Logs
- Users
